# Annmariya Wilson — Personal Portfolio & Showcase

A modern, high-performance web application designed for seamless hosting on [Vercel](https://vercel.com).

## 🚀 Live Demo & Hosting

This repository is pre-configured for instant zero-configuration deployment to Vercel:

1. Import the repository in [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Other / Static**.
3. Click **Deploy**.

## 🛠️ Tech Stack & Features

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, Dark/Light Themes), Modern JavaScript (ES6+).
- **Styling**: Tailored HSL & hex palettes, CSS Custom Properties, Responsive Grids, Micro-interactions.
- **Interactivity**:
  - Light & Dark mode switcher with local storage persistence
  - Interactive project showcase with category filters & dynamic detail modals
  - Contact form with visual submit feedback
  - Ambient mouse-glow reactive background
- **SEO & Performance**: 100% Mobile Responsive, Fast Page Load, Security Headers configured in `vercel.json`.

## 📁 Repository Structure

```text
├── index.html       # Main landing page & semantic markup
├── style.css        # Design tokens, theme variables & styling
├── script.js       # Client-side interactions & theme handling
├── vercel.json      # Vercel deployment routing & security headers
└── README.md        # Documentation
```

## 💻 Local Development

To run locally:
Simply open `index.html` in your browser or run a lightweight local server:
```bash
npx serve .
```
